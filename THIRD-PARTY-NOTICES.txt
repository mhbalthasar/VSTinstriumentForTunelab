The VST3/AU host uses the OwnAudioVST3 managed wrapper and its native
`ownvst3.tlvsti` library (MIT). The native library contains the Steinberg VST3
SDK and pugixml under MIT-compatible terms. The LV2 instrument host is
dependency-free managed code; it uses only the public LV2 C ABI and no lilv
binary. LV2 Gtk2/Gtk3/Qt5 UI hosting uses a vendored Suil 0.10.26 (ISC).

In particular:

- CLAP is a specification and C ABI published by the CLAP authors
  (https://cleveraudio.org). Only the ABI layout is re-declared here; no CLAP
  SDK source is copied or redistributed.
- VST2.4 is a specification published by Steinberg. Only the ABI layout
  (AEffect, dispatcher opcodes, audioMaster opcodes) is re-declared here from
  the public specification. No VST2 SDK source is included.
- VST3 uses the OwnAudioVST3 native host (MIT), which embeds Steinberg VST3 SDK
  and pugixml code under MIT licences. The full notices are appended below.
- AU (macOS) uses the same OwnVST3 native host and Apple's system frameworks;
  no Apple framework is redistributed.
- LV2 uses the public LV2 C ABI only. No lilv binary is redistributed.
- Suil 0.10.26 (ISC) is vendored for native Gtk2/Gtk3/Qt5 LV2 UI hosting.
  The source tree is under `Bridge/Process/Native/suil`; the Linux x64
  runtime and wrapper modules are under its `linux-x64` directory. Suil's
  ISC license text is shipped beside those binaries.
- The TuneLab SDK and TuneLab Foundation assemblies are host-provided.
  They are referenced with Private=false and are not redistributed with this
  extension. See the TuneLab project for their license.

The out-of-process bridge design was informed by the TuneLab experimental
"epmixer" insert host. All process-global names and native component suffixes
in this project differ from that project on purpose:

  TuneLab.VstBridge            -> TuneLab.VstInstrumentBridge
  tunelab-vstbridge            -> tunelab-vstinstrument-bridge
  ownvst3.tlhost (upstream)    -> ownvst3.tlvsti
  TUNELAB_BRIDGE_DIR           -> TUNELAB_VSTI_BRIDGE_DIR

The VST3/AU native host is covered above. If a future phase adds another
native shim, its license and notices must be added here before distribution.

# Third-party notices

The OwnAudioVst package (the `OwnVST3Host` assembly and the native `ownvst3` library in
`runtimes/`) is MIT licensed. The native library contains code from the projects below, all
under MIT-compatible terms. Nothing in the package is under the AGPL or the JUCE licence:
since 2.0 the native host no longer uses JUCE.

| Component | Version | Licence | Used for |
|---|---|---|---|
| Steinberg VST 3 SDK (`pluginterfaces`, `base`, `public.sdk` hosting and moduleinfo sources) | 3.8.1 | MIT | loading and running VST3 plugins, `moduleinfo.json` |
| pugixml | 1.15 | MIT | plugin cache XML, VST3 state container XML |
| OwnVST3 host (ModernMube/OwnVST3, 6a838e3) | – | Unlicense (public domain) | starting point of the VST3 backend |
| Apple AudioToolbox, AVFoundation, CoreAudioKit, AppKit / UIKit | system | Apple system frameworks, linked, not redistributed | AudioUnit hosting on macOS and iOS |

The VST3 SDK sample plugins (`adelay`, `again-sample-accurate`, `mda-vst3`, …) are built in CI
for the tests only. They are not part of the package.
